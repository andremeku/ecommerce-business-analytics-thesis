# Raw data (not redistributed)

The research uses `Sales Transaction v.4a.csv` (536,350 records, eight original fields).

Download the dataset from Kaggle: https://www.kaggle.com/datasets/gabrielramos87/an-online-shop-business
Place it here with the exact filename `Sales Transaction v.4a.csv` and run the project scripts from the repository root.

The original data ZIP provided by the researcher was deliberately *not* bundled into this public GitHub package. Check the dataset's current license on Kaggle before rehosting raw data.

The accompanying data/tableau_exports/ files are small aggregated outputs generated from the supplied source CSV.
